# Pattern Sentinel

Örümcek ağı temalı, web sunucusu kullanmayan PySide6 masaüstü kapasite planlama uygulaması.

```powershell
python -m pip install -r requirements.txt
python main.py
```

Excel'de şu alanlar bulunmalıdır: Parça No, Parça Adı, Pattern/Kalıp No, Makine/Pres, Aylık Üretim Adedi ve Çevrim Süresi (sn). Sık kullanılan farklı kolon adları otomatik tanınır.
